# Data

**File:** `cardio.arff` — Cardiovascular Disease dataset (dataset #19)
**Source:** OpenML, dataset id 45547 → https://www.openml.org/d/45547
**Size:** 70,000 patients, 13 columns, about 3 MB

We keep a copy here so the notebook runs without internet (for example during lab demos).
The notebook loads it with a relative path: `data/cardio.arff`.

If the file is ever missing, download it from the OpenML link above and save it here as `cardio.arff`.
